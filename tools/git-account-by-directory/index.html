Git 按目录自动区分提交账号

发表于 2026-08-25 分类于 工具 阅读次数： Waline： 本文字数： 5.9k 阅读时长 ≈ 5 分钟

如果一台电脑上同时维护公司项目和个人项目，最容易遇到的问题就是 Git 提交账号混用：公司仓库不小心使用了个人邮箱，或者个人项目被提交成了公司账号。

Git 支持通过全局配置中的 includeIf，根据仓库的 Git 目录路径自动加载不同的配置文件。配置完成后，只要仓库放在约定的目录下，就可以自动使用对应的 user.name 和 user.email，不需要为每个仓库单独执行 git config --local。

8.7 IDE 或 Git GUI 显示了不同账号

IDE、SourceTree、IDEA、VS Code 等工具可能：

  • 为单个仓库写入本地 user.name 或 user.email；
  • 通过环境变量指定作者信息；
  • 缓存了旧的仓库状态；
  • 显示的是历史提交作者，而不是下一次提交身份。
