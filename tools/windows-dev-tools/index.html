二、Windows 包管理方式对比

Windows 上常见的包管理方式主要有 winget、Chocolatey 和 Scoop。三者都可以安装和升级软件，但定位略有不同：

包管理方式 特点 常用命令 更适合的场景
winget Windows 官方包管理工具，通常随 App Installer 提供 winget search <名称>
winget install <名称>		 安装桌面软件和常见开发工具，优先使用系统官方生态
Chocolatey 软件包生态成熟，支持安装器、脚本和企业内部源 choco search <名称>
choco install <名称>		 管理软件种类较多，或需要企业级软件源和脚本能力
Scoop 以用户目录安装命令行工具，通常不需要管理员权限 scoop search <名称>
scoop install <名称>		 安装开发者常用 CLI 工具，保持环境轻量、便于迁移

简单选择建议：日常桌面软件可以优先考虑 winget；需要更丰富的软件包管理和企业内部源时，可以选择 Chocolatey；如果主要安装命令行工具，Scoop 通常更加方便。不同包管理器可能维护相同软件，建议为同一个工具选择一种方式管理，避免重复安装。

三、基础命令行工具

下面这些工具覆盖了日常开发中比较常见的文件、文本和终端操作场景：

工具 用途 安装命令（Winget） 备注
Windows Coreutils 提供 ls、grep、cat 等 75+ 个 Linux 常用命令 winget install Microsoft.Coreutils 微软官方出品，使用 Rust 重写
PowerShell 7 新一代 PowerShell，支持预测补全 winget install --id Microsoft.PowerShell --source winget 安装后使用 pwsh 启动
Ripgrep（rg） 快速搜索文本，替代 grep winget install BurntSushi.ripgrep.MSVC 适合搜索代码和日志
fd 更友好的文件搜索工具，替代 find winget install sharkdp.fd 速度快，语法简单

四、常用工具安装

下面的大部分工具可以通过 Scoop 安装；gh 按 GitHub 官方推荐使用 winget 安装。执行 Scoop 命令前，请先确认系统中已经安装并可以使用 Scoop。

工具 用途说明 推荐安装命令 常用示例
bat cat 的增强版，支持语法高亮、行号和 Git 修改标记 scoop install bat bat README.md
btop 终端资源监控工具，用于查看 CPU、内存、磁盘、网络和进程 scoop install btop btop
duf df 的替代品，用于查看磁盘和文件系统使用情况 scoop install duf duf
dust du 的替代品，用于分析目录和文件的磁盘占用 scoop install dust dust
exiftool 读取、写入和编辑图片、音视频等文件的元信息 scoop install exiftool exiftool image.jpg
eza ls 的现代替代品，支持颜色、目录树和 Git 状态 scoop install eza eza -la
fastfetch 快速显示系统、硬件和运行环境信息 scoop install fastfetch fastfetch
ffmpeg 处理音视频的命令行工具，支持转换、剪辑和转码 scoop install ffmpeg ffmpeg -i input.mp4 output.mp4
fzf 通用模糊搜索工具，可用于交互式筛选文件和命令 scoop install fzf rg --files | fzf
gh GitHub 官方命令行工具，用于管理仓库、Issue 和 Pull Request winget install --id GitHub.cli gh auth login
tldr 提供简化的命令示例，帮助快速了解命令用法 scoop install tldr tldr rg
